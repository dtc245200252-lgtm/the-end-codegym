Nhúng CSS Vào Trang HTML

Minh họa 3 cách nhúng CSS cơ bản: Inline Style, Internal Style và External Style

Phần 1: Inline Style

Tiêu đề định dạng bằng Inline-style

Đoạn văn này được thay đổi màu sắc trực tiếp thông qua thuộc tính style="color: #92400e;" được viết ngay trong thẻ HTML.

Phần 2: Internal Style

Tiêu đề định dạng bằng Internal-style

Đoạn văn này được thay đổi màu sắc thông qua thẻ <style> khai báo ở phần <head> của trang HTML.

Phần 3: External Style

Tiêu đề định dạng bằng External-style

Đoạn văn này được thay đổi màu sắc thông qua file CSS bên ngoài (style.css) được liên kết bằng thẻ <link rel="stylesheet" href="style.css">.
