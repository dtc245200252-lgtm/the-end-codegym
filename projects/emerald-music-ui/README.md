# [Thực hành] Sử dụng màu sắc trong trang web

Bài thực hành luyện tập sử dụng phối màu đơn sắc (monochromatic color scheme) trên trang web theo hướng dẫn của CodeGym.

---

## 1. Bảng màu đơn sắc chính (Màu xanh Logo CodeGym)

* **Bậc 1 (Màu chủ đạo):** `#00ADEE` – Dùng cho nút bấm, viền nổi bật, nhãn ON SALE, tiêu đề & nút PREVIEW.
* **Bậc 2:** `#00B2EF` – Trạng thái hover của các nút hành động.
* **Bậc 4:** `#00BFF2` – Màu nền phần banner chính.
* **Bậc 7:** `#8DD7F7` – Màu nền các thẻ nội dung danh sách nhạc nghe thử (Preview items).
* **Bậc 9:** `#C6E9FA` – Màu nền khu vực footer.
* **Màu chữ toàn trang:** `#000000` (đen) để đảm bảo độ tương phản cao, dễ đọc trên nền sáng.

---

## 2. Bảng màu mở rộng - Bước 8 (Tông màu Xanh Ngọc Lục Bảo - Emerald)

* **Bậc 1 (Chủ đạo):** `#10B981`
* **Bậc 2:** `#34D399`
* **Bậc 4:** `#6EE7B7`
* **Bậc 7:** `#A7F3D0`
* **Bậc 9:** `#ECFDF5`

File thực hiện: [`emerald.html`](file:///d:/CodeGym/emerald.html) và [`style-emerald.css`](file:///d:/CodeGym/style-emerald.css).

---

## 3. Cấu trúc thư mục

```text
CodeGym/
├── index.html          # Trang web chính áp dụng bảng màu xanh dương (#00ADEE)
├── style.css           # CSS định dạng trang web chính
├── emerald.html        # Trang web thực hiện Bước 8 với bảng màu xanh ngọc (#10B981)
├── style-emerald.css   # CSS cho bảng màu Bước 8
├── fonts/              # Font chữ đính kèm
├── images/             # Hình ảnh đính kèm
└── README.md           # Hướng dẫn chi tiết bài tập
```

---

## 4. Cách chạy và kiểm tra kết quả

1. Mở trực tiếp file [`index.html`](file:///d:/CodeGym/index.html) bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox).
2. Tại thanh header, nhấn vào **"Xem trang phối màu khác →"** để chuyển sang trang [`emerald.html`](file:///d:/CodeGym/emerald.html).
