# [Thực hành] Tạo bố cục các fixed header và fixed footer

Bài thực hành tạo bố cục trang web có Header cố định (Fixed Header / Fixed Navigation Bar) và Footer cố định (Fixed Footer) sử dụng HTML và CSS `position: fixed`.

## Tính năng
- **Fixed Header**: Menu điều hướng luôn cố định ở trên cùng màn hình khi cuộn trang (`position: fixed; top: 0;`).
- **Fixed Footer**: Thanh thông tin luôn cố định ở cuối màn hình (`position: fixed; bottom: 0;`).
- **Nội dung cuộn mượt mà**: Vùng nội dung chính có khoảng cách an toàn tránh bị che khuất bởi header và footer.
