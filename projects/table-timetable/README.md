# [Thực hành] Bảng trong CSS (table-css)

Dự án thực hành định dạng và tạo kiểu cho bảng (table) trong HTML bằng CSS theo chương trình đào tạo CodeGym.

## 📌 Nội dung thực hành

Bài học áp dụng các thuộc tính CSS cơ bản và nâng cao để tùy biến giao diện bảng:

1. **Đường viền bảng (`border`)**: Định nghĩa độ dày, kiểu viền (`solid`) và màu sắc viền cho `<table>`, `<th>`, `<td>`.
2. **Gộp viền (`border-collapse: collapse`)**: Loại bỏ khoảng cách và viền kép giữa các ô liền kề, tạo đường viền đơn gọn gàng.
3. **Kích thước bảng (`width`, `height`)**: Thiết lập bảng co giãn theo container (`width: 100%`) và tùy chỉnh chiều cao hàng tiêu đề hoặc ô dữ liệu (`height`).
4. **Căn lề ngang (`text-align`)**: Căn lề trái (`left`), phải (`right`), hoặc giữa (`center`) cho nội dung ô.
5. **Căn lề dọc (`vertical-align`)**: Căn nội dung ô lên trên (`top`), giữa (`middle`), hoặc xuống đáy (`bottom`).
6. **Khoảng cách đệm (`padding`)**: Tạo khoảng cách giữa viền ô và nội dung, giúp bảng thông thoáng và dễ đọc.
7. **Màu sắc bảng (`color`, `background-color`)**: Phối màu nền cho tiêu đề và các hàng dữ liệu, tạo tương phản rõ ràng.

## 📂 Cấu trúc thư mục

- `index.html`: Giao diện trực quan thực hành đầy đủ các ví dụ và bảng mẫu chuẩn theo bài học.
- `thoi_khoa_bieu.html`: File bài tập thực hành bảng thời khóa biểu trước đó.
- `README.md`: Tài liệu hướng dẫn và mô tả bài thực hành.

## 🚀 Cách mở bài thực hành

Mở trực tiếp file `index.html` trong trình duyệt web bất kỳ (Chrome, Edge, Firefox, Cốc Cốc, ...).
