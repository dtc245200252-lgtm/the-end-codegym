# [Bài tập] Tạo trang web với màu nền và ảnh nền

## Mục tiêu
Luyện tập sử dụng màu nền (`background-color`) và ảnh nền (`background-image`) để thiết kế trang web.

## Cấu trúc thư mục
- `index.html`: Cấu trúc trang web bao gồm thẻ `<h1>`, `<p>` và `<div>` chứa nội dung quan trọng.
- `style.css`: 
  - Thiết lập `background-color` cho trang web.
  - Thiết lập `background-image` cho thẻ `<div>`.
  - Căn giữa nội dung trong thẻ `<div>`.
- `background.jpg`: Hình ảnh nền chất lượng cao cho khối nội dung.
