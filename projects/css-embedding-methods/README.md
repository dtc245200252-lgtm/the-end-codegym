# [Bài tập] Nhúng CSS vào trang HTML

Dự án thực hành môn Web Frontend (CodeGym): Luyện tập việc nhúng CSS vào trang web bằng các cách khác nhau.

## Yêu cầu bài tập

Tạo một trang web đơn giản với nội dung bao gồm 1 tiêu đề và 1 đoạn văn cho 3 phần:
1. **Phần 1**: Thay đổi màu sắc của văn bản sử dụng **inline-style** (thông qua thuộc tính `style="..."` trực tiếp trên thẻ).
2. **Phần 2**: Thay đổi màu sắc của văn bản sử dụng **internal-style** (thông qua thẻ `<style>` đặt trong thẻ `<head>`).
3. **Phần 3**: Thay đổi màu sắc của văn bản sử dụng **external-style** (thông qua file `style.css` riêng biệt liên kết bằng thẻ `<link>`).

## Cấu trúc thư mục

```
├── index.html        # Trang HTML chính chứa cả 3 phương thức nhúng CSS
├── style.css         # File định dạng giao diện và external-style
└── README.md         # Tài liệu hướng dẫn bài tập
```

## Cách mở trang web
- Nhấp đúp trực tiếp vào file `index.html` hoặc mở bằng trình duyệt (Chrome, Edge, Firefox)
- Hoặc sử dụng extension Live Server trong VS Code để xem trực tiếp.
