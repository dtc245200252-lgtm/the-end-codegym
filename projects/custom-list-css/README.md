# [Thực Hành] Danh Sách Trong CSS (Lists in CSS)

Bài thực hành luyện tập định kiểu danh sách HTML với các thuộc tính CSS cơ bản và nâng cao theo giáo trình CodeGym.

## 🎯 Mục tiêu đạt được
- Sử dụng `list-style-type` để thay đổi kiểu đánh dấu danh sách (hình vuông, số La Mã, v.v.).
- Sử dụng `list-style-image` để tạo dấu đánh dấu bằng hình ảnh / SVG.
- Sử dụng `list-style-position` để thay đổi vị trí của dấu đánh dấu (`outside` vs `inside`).
- Sử dụng thuộc tính rút gọn `list-style` (kết hợp type, position, image).
- Thay đổi màu sắc và khoảng cách của danh sách (`background-color`, `color`, `padding`, `margin`).
- Xây dựng bài tập tổng hợp "Lộ trình học lập trình Web" với giao diện hiện đại, trực quan.

## 📁 Cấu trúc thư mục
```
List CSS/
├── index.html     # Cấu trúc HTML các phần thực hành từ mục 2 đến mục 8
├── style.css      # Toàn bộ mã CSS định kiểu cho từng danh sách
├── icon.svg       # Hình ảnh / icon dùng làm dấu đánh dấu danh sách
└── README.md      # Tài liệu hướng dẫn bài thực hành
```

## 🚀 Hướng dẫn mở và kiểm tra
1. Mở file `index.html` trực tiếp bằng trình duyệt web (Google Chrome, Microsoft Edge, Firefox).
2. Quan sát sự khác nhau giữa các danh sách:
   - Mục 2: `square`
   - Mục 3: `upper-roman`
   - Mục 4: `list-style-image`
   - Mục 5: So sánh trực tiếp `outside` và `inside`
   - Mục 6: Thuộc tính rút gọn `list-style`
   - Mục 7: Tùy biến màu sắc (`background-color`, `color`, `padding`, `margin`)
   - Mục 8: Danh sách tổng hợp Lộ trình Web
