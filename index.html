HTML5 Semantics

Nền tảng cấu trúc website chuẩn mực

  • Thẻ ngữ nghĩa: header, nav, main, section, article, footer
  • Biểu mẫu phức tạp: input types, validation, select, textarea
  • Xử lý Bảng biểu đa tầng (rowspan, colspan, caption, th, td)
  • Media & Multimedia: nhúng ảnh, audio, liên kết anchor

CSS3 & Layouts

Nghệ thuật trình bày và mô hình hộp

  • Mô hình Box Model (content, padding, border, margin)
  • Kỹ thuật căn giữa hoàn hảo chỉ với 3 dòng CSS
  • Fixed Header, Sticky Navbar, Transitions & Keyframes
Mức độ thành thạo 90%

Hướng Dẫn Xuất Bản Netlify Drop Trong 60 Giây

1

Mở Trang Netlify Drop

Truy cập vào liên kết chính thức: app.netlify.com/drop trên trình duyệt web của bạn.

2

Kéo Thả Thư Mục Dự Án

Mở File Explorer trên máy tính, kéo toàn bộ thư mục WEB-MY-BASE (chứa file index.html này cùng thư mục projects và assets) và thả vào ô vuông được chỉ định trên Netlify.

3

Nhận URL Hoạt Động & Chia Sẻ

Netlify sẽ tự động tải lên và cấp cho bạn một đường link công khai (ví dụ: https://ten-ngau-nhien.netlify.app). Bạn có thể đổi tên miền thành thaoquangvinh-portfolio.netlify.app trong phần Site Settings!

Toàn bộ 20 bài tập đều đã sẵn sàng! Khi tải thư mục này lên Netlify, tất cả liên kết đến các bài tập con đều hoạt động 100% không lo lỗi 404!
